# VirtualMouse University Presentation

Noncommercial educational engineering research presentation by Laith Al-Husseini, Al-Mustaqbal University.

This dedicated repository contains audited, compiled website files only. It includes 16 bilingual interactive scenes, licensed 3D models, verified bundled narration and a standalone audio backup. It does not include the proprietary native VirtualMouse Python application, native binaries, private checkpoints, source maps, credentials or development dependencies.

See [credits and individual licenses](credits.html). The hand and hand-derived images are CC BY-NC 4.0; other assets retain their own terms. GitHub Pages publishes the root of main. Updating requires replacing this audited static payload, preserving notices and testing the public URL.
